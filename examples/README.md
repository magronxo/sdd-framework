# Examples

Examples are educational only. They are not framework authority.

Use examples to understand possible project shapes, artifact chains, and installed SDD layouts, but do not treat them as normative.

If an example conflicts with framework contracts, follow this authority order:

1. `00_core/`
2. `01_execution/`
3. `02_policies/`
4. `templates/`
5. installed `docs/sdd/sdd.config.json`

Recommended example layout:

```text
examples/
  hello-world/
  agenticos-reference/
```

- `hello-world/` should stay minimal and generic.
- `agenticos-reference/` may show a richer real-world reference if maintained, but remains non-authoritative.
