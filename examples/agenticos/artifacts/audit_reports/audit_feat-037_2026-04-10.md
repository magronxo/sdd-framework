## Summary

feat-037 implements the wiring between `POST /api/v1/llm/chat` handler and `ProxyHardener` (from feat-028), ensuring that chat requests go through hardening gates (cooldown/rate-limit/spend) and retry logic.

### New Code (handlers_dashboard.go)

```go
// RF-01: Load provider registry
providersPath := llm.GetProvidersConfigPath()
registry, err := llm.LoadProviderRegistry(providersPath)

// RF-02: Create ProxyHardener and check gates
hardener := llm.NewProxyHardener(registry)
if hardener.IsInCooldown(providerID) { /* 429 */ }
if shouldLimit, _ := hardener.ShouldRateLimit(providerID); shouldLimit { /* 429 */ }
if hardener.ShouldDegrade(providerID) { /* 429 */ }

// RF-03: Send via WithRetry
err = hardener.WithRetry(ctx, providerID, sendFn)
hardener.RecordRequest(providerID)

// RF-04: Error mapping
// Invalid provider → 400, LLM failure → 502
```
