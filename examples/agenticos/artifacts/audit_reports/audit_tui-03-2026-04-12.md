## Problem Diagnosed

The TUI client was sending `X-AgenticOS-Surface: tui` and `X-AgenticOS-TUI-Secret` headers on POST/PUT requests but **NOT** on GET requests. This caused `DetectSurface` on the server to return `SurfaceUnknown` for GET requests, leading to:
- Rejected stepup challenges (handler requires SurfaceLocalTUI)
- Empty or degraded responses for tickets, status, logs, etc.

## Solution Applied

Centralized header setting via `setCommonHeaders(req)` helper called by all three HTTP methods (doGet, doPost, doPut).

### Code Changes

**New helper method** (`client.go:48-53`):
```go
func (c *Client) setCommonHeaders(req *http.Request) {
    req.Header.Set("X-AgenticOS-Surface", "tui")
    if c.TUISecret != "" {
        req.Header.Set("X-AgenticOS-TUI-Secret", c.TUISecret)
    }
}
```

**Modified**: doGet, doPut, doPost now call `c.setCommonHeaders(req)` instead of inline header setting.
